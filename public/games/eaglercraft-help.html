Connecting to Eaglercraft 1.12.2

Eaglercraft 1.12.2 is a real port of Minecraft Java Edition 1.12.2 compiled with WebAssembly & TeaVM. If the current mirror does not load or is blocked by your network filter:

  • Use the Mirror Switcher dropdown right above the game screen to toggle between Orion, Deevis, Official, or GitHub mirrors.
  • Click Fullscreen to get the true Minecraft experience with full Pointer Lock (mouse look).
  • Click inside the game window once to lock mouse control (press ESC to release mouse).

Popular Public Eaglercraft 1.12.2 Multiplayer Servers

Go to Multiplayer -> Direct Connect or Add Server:

  • wss://mc.arch.lol
  • wss://aeon-network.net/1.12
  • wss://eagler.asia/

Note: WebSocket servers (wss://) are required because web browsers connect through WebSockets instead of raw TCP sockets.

Keyboard & Mouse Bindings

  • WASD - Movement
  • Spacebar - Jump / Swim
  • Left Click - Mine / Attack
  • Right Click - Place Block / Interact
  • E - Open Inventory & Crafting
  • Shift - Sneak / Crouch
  • Ctrl or Double-tap W - Sprint
  • 1-9 - Quick Select Hotbar
  • Q - Drop Held Item
  • ESC - Game Menu / Release Mouse
